Vibes Quantum Server

This service distributes trainer-approved knowledge to connected Vibes apps, including Vyron X. Knowledge is made available only after review and approval in the Vibes Quantum training application.

API base: https://vibesquantum.duckdns.org

Health check: /api/health

Administrative training, review queues, provider configuration and app-key management are not part of this public landing page. Authorized operators use the restricted console at /console/ and must authenticate. Do not place secrets in URLs or client code.

Chat and AI requests use HTTPS/TLS. This does not by itself provide end-to-end encryption: when the server processes a prompt or generates an AI answer, the server can access that content. True end-to-end encrypted messages are possible only when the server cannot decrypt them; such messages cannot simultaneously be read by server-side AI or approved-knowledge processing.
